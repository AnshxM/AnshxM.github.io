# Ansh Mangalampally · Portfolio

Static personal portfolio (HTML/CSS/JS, no build step), hosted on GitHub Pages at https://anshxm.github.io.

## Edit
- Content: `index.html`
- Styles and colors: `styles.css` (theme tokens at the top)
- Photo: `assets/ansh.webp`

## Deploy
Push to the `main` branch of the `AnshxM.github.io` repo. GitHub Pages rebuilds automatically in about a minute.
